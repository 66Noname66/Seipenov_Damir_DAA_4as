### Requirements
- Java JDK 17
- Maven 3.8+

### Build project

```bash
mvn clean package
```

### Run tests

```bash
mvn clean test
```

### Run experiment

```bash
mvn -q -DskipTests package
java -cp target/classes daa.ExperimentRunner
```

### Algorithms

1. Recursive Edit Distance
2. Table Edit Distance
3. Two Rows Edit Distance
4. Naive String Search
5. KMP String Search
6. LPS Prefix Function
